# Moolah Tranche 2 Design Plan

Generated on 2026-04-26

## Purpose

Define how Tranche 2 should feel visually and structurally.

This is not the funnel.
This is not onboarding.
This is not the founder scorecard.

This is the archive world.

## Design Goal

Make the archive feel like:

- club memory
- sports civilization
- glassy but serious
- richer than Tranche 1
- visibly distinct from foyer and founder surfaces

The user should feel:

- they have crossed into depth
- this world has continuity
- history matters here

## Surface Principles

### 1. Distinct from Tranche 1

The archive world cannot reuse:

- the same hero block
- the same side-card pattern
- the same repeated pale emphasis card
- the same rhythmic three-card stack on every page

Tranche 2 must look like a different chapter of the same brand.

### 2. Glass first, not card spam

The user explicitly wants the glassmorphism feel to remain.

So the right move is:

- layered glass panels
- blurred overlays
- colored atmospheric gradients
- stronger silhouette contrast

Not:

- generic dashboard cards everywhere

### 3. Different worlds, different palettes

Each surface needs its own visual posture.

#### Archive hub

- deep navy
- brass / old gold
- restrained neutral glass

#### NBA archive

- deeper red / wine pressure
- darker blue counterbalance
- more arena-like contrast

#### Member profile

- warmer, more personal
- still archival, but less severe

#### Franchise page

- bolder, more emblematic
- one clear team-world color direction

## Required Information Architecture

### Archive hub

Order:

1. what this world contains
2. sport gateways
3. what gets preserved here
4. active vs defunct franchise logic

### Member profile

Order:

1. identity hero
2. current franchises
3. identity ledger
4. awards and honors
5. rivalry and head-to-head depth
6. archive timeline

### NBA archive

Order:

1. sport identity hero
2. season archive summary
3. awards system
4. franchise map
5. rivalry / head-to-head layer

### Franchise page

Order:

1. franchise identity hero
2. active / defunct status
3. era summary
4. titles / awards / record summary
5. current or last known steward
6. rivalry and archive notes

## Component Rules

### Use

- hero slabs
- glass rails
- archive tables
- timeline bands
- compact stat blocks
- badges for statuses like `Defunct`, `Active`, `Awaiting import`

### Avoid

- explanatory text walls
- orphaned emphasis boxes
- light cards that say one sentence just because every section needs a contrast move
- repeating one container pattern everywhere

## Typography

Keep the same system roots:

- display + body + mono

But Tranche 2 should lean more into:

- mono for archival labels
- strong compressed heading moments
- denser information rails

The tone should feel:

- documented
- earned
- less sales-like

## Copy posture

Archive copy should be:

- sparse
- factual
- quietly proud
- never startup-foggy
- never over-sentimental

Good posture:

- `Top division seasons: 6`
- `Lower division seasons: 3`
- `Defunct, still counted`
- `Awards live here too`

Bad posture:

- over-explaining why archives matter
- moralizing the emotional benefit too explicitly
- trying to “sell” the archive after the user is already inside it

## Empty states

Tranche 2 empty states must feel like:

- bones are ready
- import is pending
- history will arrive here

Not:

- broken
- dead
- fake-complete

Example posture:

- `Awaiting imported standings`
- `Award slots are ready`
- `This franchise has a page even before every season is loaded`

## Motion

Use subtle:

- gradient drift
- glass shimmer
- hover elevation

Avoid:

- loud hero animations
- gimmicky scroll reveals

Tranche 2 should feel more permanent than promotional.

## Success criteria

The design succeeds when:

- archive pages feel clearly different from funnel / foyer / founder
- glassmorphism still feels central
- the pages look like they were built for memory, not conversion
- the user can imagine a very deep world landing into these bones later
