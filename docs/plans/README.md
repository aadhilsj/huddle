## Recommended Reading Order

1. Read the design doc first.
2. Read the CEO plan second.
3. Read the engineering review third.
4. Read the design review fourth.
5. Read the metrics/classification spec if you are wiring the founder dashboard or city categories.
6. Read the scorecard UI spec when implementing or cleaning up the founder dashboard.
7. Read the foyer empty-state spec when tightening the member-side first-entry experience.
8. Read the origin story doc when aligning the team on brand continuity or writing the public story page.
9. Read the Tranche 2 product, design, and engineering plans when moving from the foyer into profiles, archives, records, awards, and rivalry depth.
10. Use the CEO plan for company direction, the engineering review for what to build first, the design review for how the first tranche should feel and behave, and the metrics/UI specs for how founder and member surfaces should be grounded in real product behavior.
